# Pkript/リファレンス/文法/正規表現

正規表現リテラルの構文と照合時の制限事項。

## リファレンス

### 構文

```text
/パターン/フラグ
```

| フラグ | 説明 |
| --- | --- |
| g | 全件一致 |
| i | 大文字・小文字の区別を無視 |
| m | 複数行モード（^ と $ が行頭・行末に一致） |
| s | 単一行モード（. が改行にも一致） |

- UTF-8解釈は常に有効
- 設定定数 PKRIPT_REGEX が 1 の場合にリテラルとして解釈される

### バックトラック制限

ReDoS（破滅的バックトラック）を防止するため、1回の照合で許されるバックトラック量は PKRIPT_REGEX_BACKTRACK（既定 100,000）に制限されている。
上限を超えた照合はエラーとなり、try / catch で捕捉することはできない。

## 使用法

### 文字列の置換を行う

```js
const text = "2026-08-31";
const formatted = text.replace(/(\d{4})-(\d{2})-(\d{2})/, "$1年$2月$3日");
return "<p>" + formatted + "</p>";
```
