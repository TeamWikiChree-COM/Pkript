# Pkript/文法/テンプレートリテラル

バッククォートを用いた文字列生成と式の埋め込み構文。

## リファレンス

### 構文

バッククォートで囲み、${} の中に式を書く。

- バッククォートで囲まれた範囲は改行をそのまま文字列に含む
- ${} には任意の式を書ける。関数呼び出しも入れ子のテンプレートリテラルも可
- ${式} の評価結果は String() と同じ規則で文字列化される（null は空文字列）
- エスケープシーケンスは通常の文字列リテラルと同じ。追加で \` と \$ が使える
- 文字列リテラル内の } は ${} を閉じない

## 使用法

### 複数行のHTML構造を生成する

```js
const cls = e.opts["class"];
const rows = e.args.map((a) => `<li>${htmlsc(a)}</li>`).join("");
return `<ul class="${cls}">
  ${rows}
</ul>`;
```
