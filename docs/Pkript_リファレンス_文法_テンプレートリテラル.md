# Pkript/リファレンス/文法/テンプレートリテラル

バッククォートを用いた文字列生成と式の埋め込み構文。

## リファレンス

### 構文

```text
`文字列 ${式} 文字列`
```

- バッククォート（`）で囲まれた範囲は改行をそのまま保持する
- ${式} の評価結果は文字列に変換されて展開される（null の場合は空文字列）
- エスケープシーケンス: \`、\$、\n、\t、\\ などが使用可能

## 使用法

### 複数行のHTML構造を生成する

```js
const title = e.args[0] || "無題";
const user = e.user.name || "名無し";
return `<div class="card">
  <h3>${htmlsc(title)}</h3>
  <p>作成者: ${htmlsc(user)}</p>
</div>`;
```
