# Pkript/リファレンス/文法/import

外部スクリプトの関数を取り込むモジュール構文。

## リファレンス

### 構文

```text
import "スクリプト名";
```

- スクリプトのトップレベルでのみ記述可能
- 読み込み先で定義された関数・グローバル変数が自スクリプトに展開される
- 同名シンボルの衝突時はエラー（上書きされない）
- 循環インポートおよび重複インポートは自動的に1回に抑制される

### 制限とセキュリティ

- 最大読み込み数: PKRIPT_MAX_IMPORTS（既定 16）
- 最大深度: PKRIPT_MAX_IMPORT_DEPTH（既定 4）
- 信頼度: 自分より低い信頼度のスクリプトは原則 import 不可。実行全体の信頼度は関与した全スクリプトの最低値となる

## 使用法

### 共通ユーティリティを読み込んで利用する

```js
import "string_utils";

function plugin_main_convert(e) {
    return "<p>" + htmlsc(truncateText(e.args[0], 50)) + "</p>";
}
```
